# Week 2: Data Cleaning and Pre-Processing

## Project Overview
This project focuses on cleaning and preparing the Student Performance Dataset using Python.

## Objectives
- Inspect the dataset and understand its structure.
- Identify missing values and duplicate records.
- Detect potential outliers using the IQR method.
- Prepare a cleaned dataset.
- Visualize the distribution of students' final grades.

## Tools Used
- Python
- Pandas
- Matplotlib

## Data Cleaning Methods
The dataset is inspected using Pandas to understand its rows, columns, data types, and missing values. Duplicate records are identified and removed when found. Numerical columns are examined for potential outliers using the Interquartile Range (IQR) method.

## Feature Engineering
The dataset can be further prepared by selecting useful columns, creating meaningful features, and applying encoding or scaling when required for later analysis.

## Expected Outcome
The Python script is designed to save a cleaned CSV file and generate a histogram of final grades. Actual results should be checked after running the script.

## Conclusion
This task develops practical skills in Python data handling, data quality inspection, cleaning methods, and visualization. The documented process supports reproducible data analysis.
